# One question, twenty answers, and no number you can trust yet

Ask "recommend a running shoe" twenty times and the same brand gets named anywhere from 1 time to 18. One run produces a number, but that number is noise.

GEO — generative engine optimization, the practice of getting a brand named inside AI answers — has a measurement problem search does not have. A search engine returns the same page for the same query all day. A generation model samples: it picks the next word from several plausible candidates, each pick carrying randomness.

This page runs that experiment: same model, same day, same prompt, twenty runs. What one run is worth, how many runs it takes to say something defensible, what a reported number has to carry.

## Three runs, three different brand lists

Same model, same day, same information available. "Recommend a running shoe," three times:

- Run 1: ASICS, Saucony, Nike, Brooks. Four brands.
- Run 2: ASICS, Nike, Hoka, Xtep, Li-Ning, 361°, Saucony. Seven.
- Run 3: ASICS, Nike, Hoka. Three.

ASICS and Nike show up in all three. The list length swings from three to seven. In run 7 the top brand is neither of them — it is 361°, which sat at #6 in run 2. **The same brand, in the same prompt, moves five positions.**

## Why the answer keeps moving

A generation model does not look a brand up in a table. It picks the next token one at a time, and at every step several tokens are plausible. The dice decide which wins, so the same opening sentence grows into two different answers.

The same prompt, on the same day, on the same model, can therefore return contradictory answers twice in a row. Not a bug — that is what sampling means.

Some answers are not answers. In runs 13 and 19 the model recommended no running shoe — it asked back: "What's your budget?" and "Wide foot or narrow foot?" **Both score as zero mentions, but they do not mean "this brand ranked low." They mean the round never reached brand comparison.** Fold those into the same count as a genuine low ranking and the number means nothing.

## How many runs it takes before the number counts

Run count decides how precise a claim you can make. That is arithmetic, not instinct.

Take a brand whose true mention rate is 65% — Saucony here, named in 13 of 20 runs. The half-width of the 95% interval at each sample size:

| Runs | Point estimate | 95% interval | Half-width |
|---|---|---|---|
| 1 | 100% | 20.7% — 100% | ±39.7pp |
| 5 | 60% | 23.1% — 88.2% | ±32.6pp |
| 20 | 65% | 43.3% — 81.9% | ±19.3pp |
| 50 | 64% | 50.1% — 75.9% | ±12.9pp |
| 100 | 65% | 55.3% — 73.6% | ±9.2pp |
| 200 | 65% | 58.2% — 71.3% | ±6.6pp |

At one run the interval is wide enough to include "this brand was never mentioned." At twenty runs it is still ±19 percentage points. **Saucony and New Balance are 20 points apart in the 20-run experiment, but their intervals overlap heavily — those two numbers alone cannot separate the brands.**

Double the sample and the interval narrows by about a third. Precision scales with the square root of the sample, so it takes four times the runs to halve the interval. **Each extra round buys less than the last. Stop when the precision is good enough.**

## Three numbers, not one

Twenty answers do not read as a verdict. They read as a distribution, and a distribution has three parts.

- **Mention rate**: named in 18 of 20 runs, reported as 90%, with its 95% interval attached (69.9% — 97.2%). The interval is wider than the point estimate — that is the story.
- **Rank range**: ASICS lands between #1 and #5, median #1. 361° lands between #1 and #7, median #5. **One brand, one prompt, six positions of spread.**
- **Answer shape**: in 2 of 20 runs no brand was named at all. Report those two separately, or state how many runs never reached brand comparison.

Report all three together: **mention rate, interval, rank range.** A bare percentage hides how shaky the number is.

"Running shoes for beginners doing long slow miles," five times:

- Run 1: ASICS, New Balance, Saucony, Hoka, Brooks.
- Run 2: ASICS, New Balance, Brooks, Saucony, Hoka.
- Run 3: ASICS, Brooks, Hoka.
- Run 4: New Balance, ASICS, Saucony.

Nike is named in 18 of 20 runs under the broad prompt, and in 1 of 15 under the narrow one. New Balance moves the other way, from 45% to 93.3%. **The model did not change its position on anything. The question changed, and the question decides what the answer is about — so the brands named change with it.**

So **changing the wording changes the market you are measuring.** A number holds for the exact sentence it came from, and any claim about "how loud my brand is in AI" has to name that sentence.

## One prompt is not a measurement

Three things to carry away.

**First, a single run is not a number.** It is one sample, and the sampling swing can be larger than the gap between brands. A 90% from one run and a 90% from twenty runs are two different claims wearing the same clothes.

**Second, report the interval.** Every page says how many runs, which prompt, which model, which date. The interval is uglier than the point estimate. It is also the honest part.

**Third, the prompt set is the definition.** Change the wording and the ranking can flip. **What gets measured is not "how loud the brand is" but "under this set of prompts, how often these brands get named."**

The next two pages cover dividing share, and keeping search share separate from share inside AI answers.
