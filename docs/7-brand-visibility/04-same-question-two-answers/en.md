# Ask the same question twice and the model gives two different answers

**One prompt does not produce one number. Ask "recommend a running shoe" twenty times and the number of times a brand gets named ranges from 1 to 18. A single run tells you almost nothing.**

GEO — generative engine optimization, the practice of getting a brand named inside AI answers — has a measurement problem that search does not. A search engine returns the same page for the same query all day. A generation model samples: it picks the next word from several plausible candidates, and the roll of the dice at each step decides how the answer comes out.

This page runs one real experiment on that. Same model, same day, same prompt, twenty runs. The results show what a single measurement is worth, how many runs it takes to say something defensible, and what a reported number has to carry.

## The same prompt produced three different answers

"Recommend a running shoe" — same model, same day, same available information, three runs, three answers with three different brand lists.

- Run 1: ASICS, Saucony, Nike, Brooks. Four brands.
- Run 2: ASICS, Nike, Hoka, Xtep, Li-Ning, 361°, Saucony. Seven.
- Run 3: ASICS, Nike, Hoka. Three.

ASICS and Nike appear in all three. The length of the list runs from three to seven. In run 7 the top brand is neither of them — it is 361°, which sat at #6 in run 2. **The same brand, in the same prompt, moves five positions.**

Run 2 and run 3 do not contradict each other. They are two draws from the same distribution, and one of them happened to name twice as many brands. Read as a single answer, run 2 says "this market has seven brands in it" and run 3 says "three". Neither statement survives contact with the next run.

## Why the answer moves at all

A generation model does not look a brand up in a table. It picks the next token, one at a time, and at each step several tokens are plausible. Which one gets picked carries randomness. The same opening sentence can grow into two different answers.

The consequence: **the same prompt, on the same day, on the same model, can return contradictory answers twice in a row.** That is not a bug. It is what sampling means.

A second layer sits on top. Some answers are not answers. In runs 13 and 19, the model recommended no running shoe at all and asked back: "What's your budget?" and "Wide foot or narrow foot?" **Both score as zero mentions, but they do not mean "this brand ranked low." They mean the round never reached brand comparison.** Fold those into the same count as a genuine low ranking and the number stops meaning anything.

## How many runs it takes before the number counts

The number of runs decides how precise a claim you can make. That is arithmetic, not instinct.

Take a brand whose true mention rate is 65% — Saucony in this experiment, named in 13 of 20 runs, exactly 65%. Here is the half-width of the 95% confidence interval at different sample sizes:

| Runs | Point estimate | 95% interval | Half-width |
|---|---|---|---|
| 1 | 100% | 20.7% — 100% | ±39.7pp |
| 5 | 60% | 23.1% — 88.2% | ±32.6pp |
| 20 | 65% | 43.3% — 81.9% | ±19.3pp |
| 50 | 64% | 50.1% — 75.9% | ±12.9pp |
| 100 | 65% | 55.3% — 73.6% | ±9.2pp |
| 200 | 65% | 58.2% — 71.3% | ±6.6pp |

At one run, the interval is wide enough to include "this brand was never mentioned." At twenty runs it is still ±19 percentage points — and **Saucony and New Balance are 20 points apart in the 20-run experiment, but their intervals overlap heavily. Those two numbers alone cannot separate the brands.**

Double the sample and the interval narrows by about a third. Precision scales with the square root of the sample, so it takes four times the runs to halve the interval. **Each extra round of asking buys less than the last, so stop once the precision is good enough for the claim.**

## Turning twenty answers into one number

Twenty answers do not read as a verdict. They read as a distribution.

- **Mention rate**: named in 18 of 20 runs, reported as 90%, with its 95% interval attached (69.9% — 97.2%). The interval is wider than the point estimate, and that is the whole story.
- **Rank range**: ASICS lands between #1 and #5, median #1. 361° lands between #1 and #7, median #5. **One brand, one prompt, six positions of spread.**
- **Answer shape**: in 2 of 20 runs no brand was named at all. Report those two separately, or state alongside the number how many runs never entered brand comparison.

Three things travel together: **mention rate, interval, rank range.** A bare percentage hides how shaky the number is.

## Five runs of the same prompt gave five answers

"Running shoes for beginners doing long slow miles," asked five times:

- Run 1: ASICS, New Balance, Saucony, Hoka, Brooks.
- Run 2: ASICS, New Balance, Brooks, Saucony, Hoka.
- Run 3: ASICS, Brooks, Hoka.
- Run 4: New Balance, ASICS, Saucony.
- Run 5: ASICS, Saucony, Hoka, New Balance.

Every brand appears somewhere across the five. But run 3 has no Saucony and no New Balance; run 4 has no Hoka and no Brooks. **"ASICS gets mentioned every time" holds up. "Hoka gets mentioned roughly every time" does not.**

Nike is named in 18 of 20 runs under the broad prompt. Under the narrow one it is named in 1 of 15. New Balance moves the other way, from 45% to 93.3%. **The model did not change its position on anything. The question changed, and the question decides what the answer is about — so the brands that get named change with it.**

That has a direct consequence for measurement: **changing the wording changes the market you are measuring.** A number holds for the exact sentence it came from. Any claim about "how loud my brand is in AI" has to name the sentence it was asked.

## One prompt is not a measurement

Three things to carry away.

**First, a single run is not a number.** It is one sample from a set, and the sampling swing can be larger than the gap between brands. A 90% from one run and a 90% from twenty runs are two different claims wearing the same clothes.

**Second, report the interval.** Every page says how many runs, which prompt, which model, which date. The interval is uglier than the point estimate. It is also the honest part.

**Third, the prompt set is the definition.** Change the wording and the ranking can flip entirely. **What gets measured is not "how loud the brand is" but "under this set of prompts, how often these brands get named."**

The next two pages take it further: how to divide share, and how to keep the share in search results separate from the share inside AI answers.
